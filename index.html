rmpUI

Design the 1-bit screens of Rytm Sidecar plugins: animated knob graphics, whole pages, fonts. What you see here is pixel for pixel what the Rytm shows, and it exports as C for your plugin.

🤖 Best with an agent

The plugin board: design the whole plugin at once

Give it your plugin's manifest.json. Every parameter appears on its real Rytm page, in its real slot, with its label, so you judge the pages as a whole, not knob by knob.

It shines with an agent: it drafts every knob in several design languages at once, you compare them on the real pages, pick one and steer with notes while it refines. You can also fill it by hand, one sketch at a time.

  • Every knob in one list, each marked empty, draft or done, with its drawing and a slider.
  • The real pages, drawn exactly as the Rytm will: sweep every knob at once to see the set move.
  • Design languages: keep several looks for the same plugin and compare them side by side.
  • Export C when it's done: one file for your plugin.

In the browser: draw by hand

Draw the knob at a few values, the keys. rmpUI fills in every frame between them, so turning the knob plays a smooth animation. This is the feedback ripple from the tutorials: four drawings, 32 frames. Nothing to install; your work stays in this browser.

On your computer: design with an agent

Run rmpUI locally and a coding agent (Claude Code or another) designs with you on the plugin board: it lays out whole design languages side by side on your real pages, you pick one, then it polishes knob by knob while you watch, undo, answer and send notes from the 🤖 panel. (An illustration.)

git clone https://github.com/twwwy/rmpui.git && cd rmpui
python3 serve.py                   # http://127.0.0.1:8004, this machine only
# then give your agent the skill: skills/rmpui/SKILL.md (see the README)
