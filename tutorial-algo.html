Tutorial: an algorithm picker

Build an FM synth's ALGO display: 8 operator diagrams (25 × 45) and a big number (9 × 11), one picture per algorithm. It's a list control: nothing animates between algorithms, so it's all about making exact pictures fast. About 30–40 minutes; the later algorithms go quickly once you have the parts.

Inspired by the Elektron DN's screens. Not affiliated with Elektron.

0 Look before you draw

Every diagram is made of the same few parts:

  • Operators: a ring (a circle of radius 4, 9 pixels across) with a letter (A, B or C) from the Sidecar's small font inside. The synth has four: A, two Bs (B1, B2) and C.
  • A feedback mark: a filled 3 × 3 square at the top right of the operator that feeds back into itself.
  • Wires: solid lines from an operator down to the one it modulates.
  • Outputs: the operators you hear run down to the bottom edge. Output X is a solid line ending in a 3-pixel foot; output Y is dotted.

Two ideas make this quick:

  1. Frames = number of items. With 8 frames and a key at each frame's value, the screen only ever shows your keys, never an in-between. So you just draw 8 pictures.
  2. Build an operator once, then paste it. An operator is three objects: a white-out (a filled circle that erases, so wires don't show through), the ring, and the letter. Select the three together and they copy, paste and move as one.

Each step's picture shows what you should have after the step. Load this result puts that into the editor.

1 Set up: 8 frames, 8 keys, nothing linked

  1. In the editor (title v9 or later), click New. Set Cell to 25 × 45 and Frames to 8.
  2. Untick New shapes linked. Every key is its own picture.
  3. Add keys so you have 0 18 36 54 73 91 109 127: click a key, + Key, type the value, Enter. These are exactly the values the 8 frames are taken at; the Frames strip shows a key's frame with a dashed blue border.

2 Build one operator (on key 0)

On key 0, make the top-right B operator of ALGO 1, centred at (18,8):

  1. White-out: tick New shapes filled, pick Circle 4 and draw a ring round (18,8), about 4 pixels out. It snaps to a circle. With Select / Edit V, drag its centre handle to (18,8) and its edge handle to (22,8). In Selected object set Ink to erase (cut out). It disappears; that's right, it only erases.
  2. Ring: untick New shapes filled and draw the same circle again: centre (18,8), radius 4.
  3. Letter: press Esc (so you start a new object), pick Pencil 8 and paint the B with its top-left at (17,6). It stays selected, so every stroke adds to it. ⌥-drag erases a stray pixel.
  4. Rename the three in Selected object → Name, e.g. "B white-out", "B ring", "letter B".

The letter's top-left is always the ring's centre − (1,2).

3 ALGO 1: paste operators, add wires

  1. Select the operator: Select / Edit V, click the ring, Shift-click the letter, and Shift-click the white-out in Objects (it's invisible on the canvas).
  2. Copy it: ⌘C ⌘V pastes a copy on top, all three selected. Drag it, or nudge it with the arrow keys (Shift+arrow moves 4), to its place.
  3. A different letter: click just the copy's letter, ⌥-drag over it with the Pencil to erase, and paint the new one.
  4. The feedback mark: Rect 5, filled, corners 0, 3 × 3 at the ring's top right (centre + (4,−6) to centre + (6,−4)).
  5. Wires: Line 2, then ▼ Behind until it's under the white-outs, so its ends tuck under the rings. A one-pixel wire is a single click.
  6. Outputs: X: a line down to row 43 and a 3-pixel foot on row 44. Y: a line with dotted ticked in Selected object, down to row 44.

4 ALGO 2 to 8: copy forward, rearrange

For each next key:

  1. On the key you just finished: ⌘A (select everything) and ⌘C.
  2. Click the next key and ⌘V. The same objects arrive there.
  3. Move operators into place (select an operator's three parts, then drag or use the arrows), fix letters, and delete wires you don't need. Add new ones.

5 The big number: a second sketch

  1. Save sketch first. It downloads the diagram, and Open sketch brings it back later. The editor holds one sketch at a time.
  2. New, Cell 9 × 11, Frames 8, the same 8 keys, New shapes linked off.
  3. With the Pencil, paint each key's digit (key 0 = 1, key 18 = 2, …). Press Esc before each new digit. A tip: paint the first, copy it to the next key, then ⌥-erase and add only what differs.

6 Put both on the Rytm screen

  1. Export each sketch with Copy JSON, named algo and algonum, into your layout's "bitmaps".
  2. Add two frames elements driven by the same param, for example at:
{ "type": "frames", "bmp": "algo",    "p": 1, "x": 18, "y": 13 }
{ "type": "frames", "bmp": "algonum", "p": 1, "x": 50, "y": 16 }

Memory: diagram 8 × 45 rows × 4 bytes = 1440 B; number 8 × 11 × 2 = 176 B. To show the diagram on every page and the number on the first page only, put the first element on every page's layout and the second on page 1.

✓ What you used

  • Frames = items, a key at each frame value: exact pictures for a list control.
  • Unlinked from the start, because every key differs.
  • A white-out (a filled circle, Ink: erase) so things behind an operator are hidden.
  • Pencil for letters and digits; Esc starts a new pencil object; ⌥ erases.
  • Multi-select (Shift-click, ⌘A), group copy / paste, and arrow-key nudging.
  • ▼ Behind for drawing order.
